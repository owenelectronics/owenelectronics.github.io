TC-05

How I work

Agents execute. The judgment is mine.

AI speeds things up, but it does not decide what to build or whether it turned out right. That is my job, and it is the same one I did for ten years as a QA and analyst.

  1. Requirement

    I gather it with the business and write the story with its acceptance criteria.

  2. Specification

    I turn the criteria into Gherkin scenarios anyone can read.

  3. Agents

    Each agent has a role: backend, interface, QA, security. They work on the repository through MCP.

  4. Tests

    Playwright and unit tests run on every change, with no manual step.

  5. Review

    I read the result, validate it against the business, and only then it ships.
